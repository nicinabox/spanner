---
title: Resetting your password
---



If you've forgotten your password, request a reset link by email. Reset works whether you've previously set a password or not.

## In the app

The [reset form](/reset-password) lets you request a reset link by email. Enter your email and Spanner sends a reset link if an account with that email exists and has a password.

If you don't currently have a password, the reset link lets you set one. If you do have a password, the link lets you replace it.

## How it works

A reset link works once and is valid for a limited time. Open the link from the email, enter a new password, and confirm it. After saving, Spanner signs you in to the app.

## Notes

The reset link is single-use. If you request another before using the first, only the latest link works.

If you can't access your email, account recovery isn't possible. Spanner doesn't store passwords in a recoverable form.
