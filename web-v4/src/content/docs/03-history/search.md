title: Search
---

Find records on a vehicle by searching notes, cost, mileage, date, or classification.

## In the app

Open a vehicle from the [Vehicles page](/vehicles), then go to **History**. The search input is above the history table.

## How it works

Type into the search input to filter records. Results update as you type, with at least two characters needed.

Search covers:

- **Notes** - any word or phrase from the notes field
- **Cost** - exact cost values
- **Mileage** - exact values plus rounded forms (75k matches 75000)
- **Date** - year, month name, and full date
- **Classifications** - the classification name and any keywords

Search is fuzzy - close matches count. Click a classification badge in the history table to fill the search with that classification's name.

## Notes

Clearing the search restores the full history list.

Search runs on the records already loaded for the vehicle. It does not query the server.
