---
title: Mobile
---

Spanner works in any browser and installs to a phone or computer for quick access. Previously visited pages remain available when offline.

## Mobile

The same URL works on phones, tablets, and desktops. The interface reflows for smaller screens to fit the available width.

There's nothing to download from an app store. Open the URL in a browser and continue.

## Offline

Pages visited before are saved locally and remain visible without a connection. Anything that writes to the server - saving records, signing in, syncing reminders - needs to wait for a connection.

A page that was never opened while online shows a brief offline message and a prompt to reconnect.

## Installing

On a touch device, an **Install** button appears in the top bar. Tap it to add Spanner to the home screen as its own app.

On a desktop browser, use the browser's install option - usually in the address bar or under the browser menu.

Once installed, Spanner opens in its own window with no browser interface around it.

## Notes

Cached pages can show older data while offline. Changes made by other devices or users don't appear until the app reconnects.

Spanner updates on its own. New versions take effect the next time the app loads a page.
